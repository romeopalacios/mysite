# Lionheart Designs website template

This version is ready for GitHub Pages and does not require Node, React, or a build step.

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Inquiry form

The form sends submissions to `rpalaciostech@gmail.com` through FormSubmit. The first test submission triggers a confirmation email. Open that email and activate the form once; future submissions will then arrive normally.

## Customize

Edit the wording in `index.html` and colors near the top of `styles.css`. Replace the displayed email address and form action together if the destination changes.
